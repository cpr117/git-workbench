# 0.12.0 验证范围

2026-10-26，macOS。本版本实现底部 Git 分支树右键菜单，以及所选分支与当前 HEAD / 工作区的整个仓库比较。

- TypeScript 编译通过；扩展入口与分支模型共 37 项相关测试通过。
- 真实临时 Git 仓库验证分支比较范围、未提交内容隔离、创建 / 检出 / 重命名 / 删除、合并和两种变基方向。
- 临时本地 bare remote 验证非当前分支推送和非当前分支快进更新。
- 覆盖取消确认、过期引用、其他仓库消息、脏工作区与同一 HEAD 上外部切换分支的拦截。
- Qoder 开发宿主实测分支右键菜单、整个项目比较、原生 Diff 文件切换和关闭标签后隐藏文件树。

Windows、Linux、Remote SSH、Dev Container 尚未独立实机验收。原生历史小窗只支持 macOS 12+ 本地工作区；其他平台请显式设置 `gitWorkbench.historyPresentation` 为 `editor`。发行包内原生组件采用 ad-hoc 签名，不代表 Apple 公证。

公开源码不包含业务仓库、用户截图、凭据、依赖缓存或本地验证产物。Git 操作仅在扩展宿主执行；插件没有遥测或运行时 npm 依赖。
